01 · EL PROBLEMA01 · THE PROBLEM

El problema no era el modelo, era lo que le pedía.

The problem wasn't the model, it was what I was asking of it.

Pedirle coordenadas a una IA es pedirle que haga de maquetador, y no lo es. Pedirle Mermaid es obligarla a cumplir una sintaxis pensada para personas. Las dos cosas fallaban por el mismo motivo: el formato no estaba hecho para quien lo escribía.

Asking an AI for coordinates means asking it to be a layout engine, and it isn't one. Asking it for Mermaid forces it to follow a syntax designed for people. Both failed for the same reason: the format wasn't made for whoever was writing it.

02 · EL ENFOQUE02 · THE APPROACH

Un lenguaje a la medida de quien lo escribe.

A language built for whoever writes it.

En vez de adaptar la IA a un formato, adapté el formato a la IA. La IA describe y el código dibuja.

Instead of adapting the AI to a format, I adapted the format to the AI. The AI describes; the code draws.

  • Pocos tokensLa forma va en los signos, sin palabras clave; [A], [B] -> [C] son dos flechas.
  • Sin ambigüedadCada pieza tiene un identificador estable; "App Server" y "app server" son lo mismo.
  • ToleranteSi falta un cierre al final de la línea, el analizador lo completa en vez de fallar.
  • Sin coordenadasEl modelo nunca decide posiciones ni tamaños; lo hace el motor de maquetación.
  • Few tokensThe shape lives in the symbols, no keywords; [A], [B] -> [C] is two arrows.
  • No ambiguityEvery piece has a stable id; "App Server" and "app server" are the same node.
  • ForgivingIf a closing symbol is missing at the end of a line, the parser adds it instead of failing.
  • No coordinatesThe model never decides positions or sizes; the layout engine does.
03 · DECISIONES03 · DECISIONS

Decisiones que tomé

Decisions I made

Coste

Cost

  • El modelo justo para cada momento. Sonnet escribe el primer diagrama, que es donde se decide la estructura. Los cambios ("añade una caché aquí") los hace Haiku, más rápido y mucho más barato.
  • Un lenguaje corto sale barato. Con pocos tokens por diagrama, la respuesta llega antes y cuesta menos. El formato era también una decisión de coste.
  • The right model for each moment. Sonnet writes the first diagram, where the structure is decided. Changes ("add a cache here") go to Haiku, faster and much cheaper.
  • A short language is a cheap language. With few tokens per diagram, the answer arrives sooner and costs less. The format was a cost decision too.

Calidad

Quality

  • Primero entender, después dibujar. Un modelo rápido convierte una petición vaga ("la arquitectura de una tienda online") en un encargo preciso. Si falla, se usa la petición original: nunca bloquea.
  • Una maquetación para cada tipo de diagrama. Arquitecturas, mapas mentales, árboles, secuencias y modelos de datos no se ordenan igual, y cada uno tiene la suya.
  • El contenido, separado del aspecto. El mismo diagrama se ve limpio, a mano alzada o cyberpunk sin que la IA lo reescriba.
  • Understand first, then draw. A fast model turns a vague request ("the architecture of an online shop") into a precise brief. If it fails, the original request is used: it never blocks.
  • A layout for each kind of diagram. Architectures, mind maps, trees, sequences and data models aren't arranged the same way, and each has its own.
  • Content separate from looks. The same diagram can look clean, hand-drawn or cyberpunk without the AI rewriting it.

Seguridad y experiencia

Security and experience

  • No fiarse de lo que llega. Los intentos de manipular al asistente se detectan, se cuentan y se bloquean, y cada visitante tiene un límite diario.
  • Hablar, adjuntar y compartir. Se puede dictar la petición, adjuntar una imagen o un PDF como contexto, compartir el diagrama con un enlace y exportarlo a SVG o PNG.
  • Don't trust what comes in. Attempts to manipulate the assistant are detected, counted and blocked, and every visitor has a daily limit.
  • Talk, attach and share. You can dictate the request, attach an image or a PDF as context, share the diagram with a link and export it as SVG or PNG.
04 · APRENDIZAJES04 · LEARNINGS

Qué aprendí

What I learned

Que el formato importa tanto como el prompt: diseñar el lenguaje para el modelo mejoró los resultados más que cualquier ajuste de instrucciones. Que lo que se puede resolver con código no se le pide a un modelo: un algoritmo coloca las cajas al instante, gratis y siempre igual. Que tolerar errores pequeños sale más barato que pedir otro intento. Que la seguridad de una app con IA no está solo en el prompt: al revisar el proyecto para escribir esta página descubrí que el servidor aceptaba instrucciones del navegador, y lo cerré. Y que una aplicación "AI-first" no es la que más IA usa, sino la que la usa donde aporta y deja el resto a lo de siempre.

That the format matters as much as the prompt: designing the language for the model improved results more than any tweak to the instructions. That what code can solve, you don't ask a model to do: an algorithm places the boxes instantly, for free and the same way every time. That tolerating small mistakes is cheaper than asking for another attempt. That the security of an AI app isn't only in the prompt: while reviewing the project to write this page, I found the server accepted instructions from the browser, and I closed it. And that an "AI-first" application isn't the one that uses the most AI, but the one that uses it where it adds value and leaves the rest to ordinary code.

05 · HOY05 · TODAY

Hoy los modelos dibujan solos. Y lo hacen igual.

Models draw on their own today. And they do it the same way.

Cuando un asistente te dibuja un diagrama, no coloca píxeles: escribe un lenguaje de texto (Mermaid, SVG, código) y otro programa lo pinta. Es la misma separación que hizo funcionar Skemly. La herramienta ha caducado; la forma de pensarla se ha convertido en la norma.

When an assistant draws you a diagram, it doesn't place pixels: it writes a text language (Mermaid, SVG, code) and another program renders it. It's the same split that made Skemly work. The tool has expired; the way of thinking about it has become the norm.

07 · CONTACTO07 · CONTACT

La IA describe. El código ejecuta. Alguien tiene que decidir la frontera.

The AI describes. The code executes. Someone has to draw the line.

Mi regla es sencilla: si algo se puede resolver con código, de forma determinista y más barata, no se le pide a un modelo. El modelo entra donde hace falta criterio; el resto es código. Si estás metiendo IA en tu producto y quieres trazar esa frontera (qué hace el modelo y qué el código, qué modelo, cuánto cuesta, cómo se protege), escríbeme y lo vemos.

My rule is simple: if something can be solved with code, deterministically and more cheaply, you don't ask a model to do it. The model comes in where judgement is needed; the rest is code. If you're bringing AI into your product and want to draw that line (what the model does and what the code does, which model, what it costs, how it's protected), write to me and let's look at it.
