Project: Vibedrawing v1.1 — Spec (LLM-first Diagramming)0. Vision & PrinciplesVibedrawing is an LLM-native diagramming tool driven by an ultra-light DSL optimized for:Low token usage: Minimal syntax, high information density.High semantic density: Meaningful delimiters and tags.Deterministic parsing: Stable ID normalization and clear rules.Automatic layout: No coordinates or manual sizing.1. Input & ExtractionThe system accepts raw DSL or a Markdown document.Extraction Rule: If fenced code blocks with language vibe or vibedraw exist, parse only the first one. Otherwise, parse the whole text as DSL.2. DSL Specification2.1 Node Literals (Shapes inferred by delimiters)[Text] → Box (Process/Entity)(Text) → Cylinder/Pill (Database/Storage/State)?Text? → Diamond (Decision/Gateway)<Text> → Cloud (External Network/SaaS/Internet)2.2 Stable IDs & NormalizationSyntax: [id|Label] (e.g., [app1|App Server]). If | is missing, id defaults to label.Normalization: id_key = trim + lowercase + collapse internal spaces to single spaces + NFC.Consistency: [App Server] and [app server] map to the same node ID.2.3 Relationships & ExpansionTypes: -> (directed), <-> (bidirectional).Labels: A -> "Label" -> B.Cartesian Expansion: [A], [B] -> [C], [D] expands to N edges (sources × targets).2.4 Tags & GroupsTags: #danger, #safe, #info, #warning (e.g., [Node]#info).Groups: group "Title" #tag { ... }. Groups can be nested.2.5 Directivesvibe: clean | handdrawn | cyberpunk (Default: clean)layout: TD (Top-Down) | LR (Left-Right) (Default: TD)spacing: <number> (Default: 40)edgeLabels: on | off (Default: on)2.6 EscapingInside labels/quotes: \", \\, \], \), \?, \>.3. Technical StackCore: React + Vite + Tailwind CSS.Layout: elkjs (running in a Web Worker for performance).Visuals: roughjs (for handdrawn theme), lucide-react (for icons).4. Implementation Logic4.1 Parser PipelineExtract: Get DSL from Markdown.Tokenize: Identify directives, groups, and relationship statements.AST: Build nodes (id_key, label, shape, tags) and edges.Auto-heal: Close missing delimiters at end-of-line (line-based only).4.2 Node AttributesAttributes are appended outside the brackets in any order: [Node]@icon=X@bg=#color@color=#color@url=https://...Supported attributes:@icon=Name — override icon (e.g. @icon=Database). Auto-inferred from label keywords: user, db, database, cloud, auth, mail/email, api, server, lb, queue, cache.@bg=#rrggbb — custom node background color.@color=#rrggbb — custom node text color.@url=https://... — attach a clickable URL to the node. Single-click opens the URL in a new tab. A small external-link indicator appears in the node corner.4.3 Layout & RenderingSizing: Derived from icon + text + padding + max-width (220px).ELK: Offload computation to Worker to keep UI responsive.SVG: Responsive canvas with Pan/Zoom and Fit-to-view.5. Vibes (Themes)Clean: Professional, slate-100 backgrounds, sans-serif font.Handdrawn: roughjs sketchy lines, marker-style font, slight jitter.Cyberpunk: Dark mode, neon borders/glows, monospace font.6. UI/UX & DiagnosticsSplit View: Editor on the left, live SVG preview on the right.Diagnostics: Panel showing syntax errors/warnings with line numbers.Export: SVG export (required) and PNG export (optional).Copy: Button to copy the clean DSL back to the clipboard.7.
